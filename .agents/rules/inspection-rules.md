# 홈페이지 점검 공통 규칙 (요약)

Antigravity가 항상 로드하는 규칙 요약이다. **원본은 `core/rules.md`** 이며 점검 전에 반드시 읽는다.

- 읽기 전용: 로그인·등록·수정·삭제·업로드·관리자 기능 금지
- 허용 도메인 밖은 접속하지 않고 URL만 기록
- 차단 의심(403/429 연속) 시 즉시 중단, 우회·재시도 금지
- 스크립트가 확정한 날짜·상태·지연 판정을 AI가 다시 계산하거나 뒤집지 않음
- 점검하지 못한 항목은 정상이 아니라 미점검으로 보고
- 개인정보는 마스킹, 외부 AI 전송은 보안 승인 후에만
