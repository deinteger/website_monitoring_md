# 검색엔진 인덱스 링크 점검

검색엔진(구글, 네이버)에 인덱싱된 URL을 수집하여 실제 접속 가능 여부를 점검한다.

## 목적

홈페이지 내부 메뉴에는 표시되지 않지만 검색엔진에 오래된 URL이 남아 있어 발생하는
사용자 접근 오류(404, 삭제 페이지, 리다이렉트 오류 등)를 탐지한다.

## 절차

1. 브라우저를 열어 Google(https://www.google.com)에 접속한다.
2. `references/inspection-targets.md`에 정의된 각 도메인에 대해 다음 검색어를 순서대로 입력한다.
   - `site:www.nihhs.go.kr`
   - `site:fruit.nihhs.go.kr`
3. 검색 결과 첫 페이지에서 최대 10개 URL을 수집한다.
4. 다음 페이지로 이동해 추가 10개를 수집하고 최대 3페이지(총 30개 URL)까지 수집한다.
5. 같은 절차를 네이버(https://search.naver.com)에서도 반복한다.
   - 네이버 검색어 예: `site:www.nihhs.go.kr`
6. 수집한 URL 중 중복을 제거한다.
7. 각 URL에 브라우저로 직접 접속하여 다음을 확인한다.
   - HTTP 응답 상태 (정상, 404, 500, 리다이렉트 여부)
   - 페이지 실제 내용이 정상적으로 표시되는지 여부
   - 검색결과에 표시된 제목·설명과 실제 페이지 제목이 일치하는지 여부
   - 접속 오류가 발생하면 최소 1회 재접속하여 재현 여부를 확인한다.
8. 결과를 `output/YYYY-MM-DD/search-index-links.csv`에 작성한다.
9. 오류가 발견된 경우 `output/YYYY-MM-DD/inspection-details.csv`에도 추가 기록한다.
10. 점검 요약을 `output/YYYY-MM-DD/inspection-summary.md`의 별도 섹션으로 추가한다.

## 제약

- 검색엔진 로그인은 수행하지 않는다.
- 검색 결과 광고 링크는 제외한다.
- 외부 도메인으로 최종 연결되는 URL은 URL만 기록하고 접속 점검은 제외한다.
- 검색엔진이 `site:` 연산자 결과를 제한하는 경우 수집 가능한 범위 안에서만 진행하고 제한 사유를 기록한다.
