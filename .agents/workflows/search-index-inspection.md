# 검색엔진 인덱스 링크 점검 (브라우저 필요)

검색엔진에 남은 오래된 URL(삭제 페이지, 404, 리다이렉트 오류)을 찾는 점검이다. 브라우저가 있는 에이전트에서만 수행한다.
스크립트가 아닌 에이전트가 직접 수행하며, 요청량이 작아 별도 요청 정책은 없다. `core/rules.md`의 안전 원칙은 동일하게 적용된다.

1. `workspace/site-profile.json`의 `allowed_domains`를 읽는다.
2. 각 도메인에 대해 Google, 네이버에서 `site:<도메인>`을 검색한다 (로그인 금지, 광고 링크 제외).
3. 결과에서 도메인별 최대 30개 URL을 수집하고 중복을 제거한다.
4. 각 URL에 접속해 상태(정상/404/500/리다이렉트), 실제 내용, 검색결과 제목과 실제 제목의 일치 여부를 확인한다. 오류는 1회 재접속해 재현을 확인한다.
5. 외부 도메인으로 최종 연결되는 URL은 URL만 기록한다.
6. `workspace/runs/YYYY-MM-DD/search-index-links.csv`에 `core/report-fields.md` 필드로 저장한다.
7. 검색엔진이 `site:` 결과를 제한하면 수집 가능한 범위만 하고 제한 사유를 기록한다.
