# 월간 보고 지표 정의

`scripts/monthly_report.py`가 `workspace/history/`의 일별 스냅샷으로 계산한다. 비교 대상은 **월말 마지막 점검**과 **전월 말 마지막 점검(없으면 그 이전의 가장 가까운 점검)**이다.

| 지표 | 정의 |
| --- | --- |
| 게시일 판정 대상 게시판 | 유형이 board이고 판정이 정상·게시 최신성 지연·게시일 확인 불가·담당자 확인 필요인 게시판 (접속 오류·제외는 분모에서 제외) |
| 게시 최신성 정상률 | 정상 ÷ 판정 대상 게시판 × 100 (소수 첫째 자리) |
| 월 중 신규 게시가 있었던 게시판 수 | 월말 기준 최신 게시일이 해당 월 1일 이후인 게시판 수 |
| 신규 등록 콘텐츠(게시글) 건수 | 목록에 표시된 **게시일이 해당 월**인 게시글 수 (게시글 키 기준 중복 제거, 게시판별 합) |
| 현행화 개선 | 전월 말 '게시 최신성 지연' → 월말 '정상'으로 바뀐 게시판 |
| 신규 지연 | 전월 말 '정상' → 월말 '게시 최신성 지연'으로 바뀐 게시판 |
| 지적 신규 발생 | 월 중 점검에서 관측된 지적 키 중 전월 말에 없던 것 |
| 지적 지속 | 전월 말과 월말 모두 있는 지적 |
| 지적 해결 | 전월 말 또는 월 중에 있었으나 월말에 없는 지적 |

## 해석상 주의 (보고서에 반드시 병기)

- 신규 등록 콘텐츠는 **수집한 목록 범위** 안에서만 집계한다. 해당 월 초까지 수집 범위가 닿지 않은 게시판은 `부분(하한값)`으로 표시한다.
- 삭제·비공개된 게시글, 수집 전에 이미 사라진 글은 반영되지 않는다.
- 증분 점검에서 방문하지 않은 게시판은 마지막 방문 시점 값이다.
- 신규 발생·해결은 점검 시점 기준이며, 점검 사이에 생기고 사라진 지적은 누락될 수 있다.
- 첫 달에는 전월 비교 기준이 없어 `비교 기준 없음`으로 표시된다. 다음 달부터 증감이 계산된다.

## AI 종합 의견 작성 규칙

- 표의 수치만 인용한다 (새로 계산·추정하지 않는다).
- 구성: ① 전월 대비 핵심 변화 1~2줄 ② 개선된 점 ③ 주의가 필요한 게시판·담당부서 ④ 다음 달 조치 제안
- 집계 한계(부분 집계 게시판 등)가 결론에 영향을 주면 함께 적는다.
