# Claude 채팅(claude.ai)에서 스킬로 사용하기

## 결론

**가능하지만 조건이 있습니다.** 채팅형 환경은 대화가 끝나면 컨테이너가 사라지고, 사이트 접속은 네트워크 허용 설정에 달려 있어서 로컬 실행(Claude Code, 스케줄러)과 같지 않습니다. 소규모 시험·간이 점검에 적합하고, 정기·대량 점검에는 로컬을 권합니다.

## 만드는 법

```bash
python scripts/make_claude_skill.py
```

`dist/homepage-inspection-claude-skill.zip`이 생성됩니다 (폴더 하나로 압축, 스크립트·판단 기준·예시 설정 포함, 약 60KB). 일반 키트와 달리 이 zip은 스킬 폴더 안에서 상대경로로 동작하도록 채팅용 `SKILL.md`를 별도로 담고 있습니다.

## 올리는 법

Claude 도움말 기준: 설정의 **Customize > Skills**에서 `+` → **Create skill** → **Upload a skill**로 zip을 올립니다. 전제 조건:

- 유료 요금제(Pro, Max, Team, Enterprise)이며 **코드 실행 및 파일 생성**이 켜져 있어야 합니다 (Team/Enterprise는 조직 관리자 설정이 필요할 수 있음).
- 커스텀 스킬은 사용자 개인 단위이며 조직에 중앙 배포되지 않습니다 → 동료에게는 zip을 각자 올리도록 안내합니다.
- 위 내용은 도움말 문서와 검색 결과 기준이며 메뉴 이름과 요금제 조건은 바뀔 수 있어 **사용 시점 확인 필요**합니다.

## 쓰는 법

대화에 `site-profile.json`(필수)과 `settings.json`(선택)을 올리고 요청합니다.

```text
homepage-inspection 스킬로 시험 점검(20개)을 하고 결과 요약과 state.zip을 줘.
```

다음 점검 때는 **지난번에 받은 `state.zip`을 올려서** "증분 점검해줘" 또는 "9월 월간 보고 만들어줘"라고 요청합니다. state.zip에는 프로필·설정·캐시·이력이 들어 있고 API 키는 들어 있지 않습니다. 이 파일이 없으면 매번 처음부터(전체) 시작하고 월간 전월 비교도 안 됩니다.

## 제약과 확인 필요 사항

| 항목 | 내용 |
|---|---|
| 사이트 접속 | 코드 실행 환경의 네트워크 정책에 달려 있음. 기본은 패키지 관리자만 허용되고 추가 허용 도메인을 설정하는 방식이라는 2차 자료가 있으나 **공식 문서로 확인하지 못함 → 사용자 설정 화면에서 확인 필요**. 막히면 스킬이 점검을 멈추고 안내하며 우회하지 않음 |
| 내부망 사이트 | 클라우드 환경에서 접근 불가 → 로컬 실행 필요 |
| 실행 시간 | 대화 1회 실행 시간 제한이 있을 수 있음(수치 확인 필요) → 시험은 `--limit 20`, 대량은 로컬 |
| 상태 보관 | 컨테이너가 사라지므로 state.zip 필수 (수동 업로드/다운로드) |
| 보안 | 점검 내용이 외부 AI 서비스로 전송됨 → 기관 보안 승인 범위 확인 (`docs/보안통보_요청서_양식.md` 6항) |
| 자바스크립트 게시판 | 기본 스크립트는 못 읽음. 채팅에는 브라우저가 없으므로 `담당자 확인 필요`로 남음 |
| 스케줄 | 채팅은 자동 실행 불가 (수동 요청) |

## 로컬과의 선택 기준

| | 채팅 스킬 | 로컬(Claude Code, pi 등 + 스케줄러) |
|---|---|---|
| 비용 | 구독 범위 | 구독 또는 API |
| 설치 | zip 업로드만 | 폴더 + Python |
| 자동화 | 불가 | 가능 |
| 내부망 | 불가 | 가능 |
| 상태 유지 | state.zip 수동 | 자동 (workspace) |
| 적합 | 시험·소규모·비개발 담당자 | 정기·대량 |
