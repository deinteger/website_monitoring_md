## 점검 범위

- 메인 페이지
- 상단 메뉴 및 하위 메뉴
- 전체 메뉴 또는 사이트맵
- 게시판
- 공지사항
- 보도자료
- 카드형 콘텐츠
- 썸네일 목록
- 행사 및 교육 목록
- 자료실 및 첨부파일

- 로그인 필요 화면
- 관리자 페이지
- 검색 결과 무한 페이지

- 최대 페이지 수: 20
- 외부 링크: URL만 기록
