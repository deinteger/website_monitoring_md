# 홈페이지 점검 결과 요약

## 1. 점검 개요

- **점검 대상**: 국립원예특작과학원 대표 홈페이지
- **시작 URL**: [https://www.nihhs.go.kr/](https://www.nihhs.go.kr/)
- **점검 기간**: 2026-07-30 (시험 점검)
- **점검 범위**: 메인 페이지, 주요 게시판, 간행물실, 소개 페이지 등 총 20개 페이지
- **기준일**: 2026-07-30
- **3개월 경과 기준일**: 2026-04-30

점검 대상 20개 페이지에서 깨진 이미지, 링크 접속 장애, 첨부파일 다운로드 실패 등의 확정 오류는 발견되지 않았습니다. (정상)

## 8. 점검 한계

- 본 점검은 **시험 점검** 목적 하에 상위 20개 대표 페이지만을 임의로 선정하여 진행되었습니다.
- 전체 메뉴의 모든 하위 페이지를 포함하는 전수 점검은 아니며, 외부 도메인 및 권한이 필요한 페이지(로그인 등)는 탐색 범위에서 제외되었습니다.

## 9. 후속 조치 제안

1. **일반자료실 현행화**: 일반자료실의 가장 최신 글이 2025-11-04로 3개월 이상 신규 등록이 지연되고 있으므로, 새로운 교육/참고자료가 있을 경우 추가 업로드 및 구버전 자료 현행화 조치가 필요합니다.
2. **간행물 등록 프로세스 검토**: 농업기술간행물 게시판은 목록 화면에 게시일 정보가 부재하여 사용자가 작성 시기를 쉽게 인지하기 어려울 수 있습니다. 목록 정보 항목에 '등록일자' 필드를 추가 노출하는 것을 권장합니다.
