02 · Python 기반 프로그램

자동 점검 결과를 파일과 대시보드로 관리

주요 기능
  • 내부 링크 기반 페이지 수집
  • HTTP 상태와 응답시간 점검
  • 콘텐츠 최신성, 링크·이미지·첨부파일 점검
  • 접근성 및 성능 점검
  • 신규·지속·변경·해결·재발 이슈 관리
  • JSON·JSONL·XLSX 보고서 생성
  • TimelyGPT 기반 점검결과 분석 기능
운영 특징 및 한계
  • 외부 DB 없이 파일 기반으로 상태와 이력 관리
  • 최대 10페이지·동시 요청 1·요청 간격 1초
  • 자동 배치와 웹 수동 실행 지원
  • 실행 잠금으로 중복 점검 방지
  • 메뉴 구조·사이트맵·WAF·프록시에 따라 수집 결과가 달라질 수 있음
  • 현재는 로컬 서버 중심이며 대규모 전체 점검은 추가 검토 필요

실행 방법

1

운영 설정과 대상 사이트를 확인합니다.

2

프로그램의 로컬 서버를 실행합니다.

3

브라우저에서 대상·최대 페이지·점검 옵션을 선택하여 실행합니다.

4

진행률과 결과를 확인하고 XLSX 보고서를 내려받습니다.

접속 주소: http://127.0.0.1:18765 ※ 서버 실행 명령은 제공된 지시서에 기재되어 있지 않음

03 · Markdown 기반 AI 프로그램

질의어 입력으로 5개 분야를 탐색·점검

점검 분야확인 내용
1. 링크 및 접속 오류404·500 오류, 내부·외부 링크와 메뉴·본문·배너의 이동 상태, 구글·네이버 등에 남아 있는 오래된 검색 노출 링크의 접속 오류
2. 화면 및 첨부파일깨진 이미지, 내용이 없거나 로딩에 실패한 빈 페이지, HWP·PDF·ZIP 등 첨부파일의 정상 다운로드 여부
3. 게시 최신성게시판별 최신 게시일 추출, 점검일 기준 3개월 이상 미등록 시 ‘게시 최신성 지연’ 분류, 연보·매뉴얼 등 연례·비정기 콘텐츠는 별도 비고 관리
4. 콘텐츠 및 문구종료된 행사·사업의 현재 진행 표기, 오래된 연도·담당자·서식, 부자연스러운 표현과 오탈자
5. 데이터 및 표기 이상연도별 관측·시스템 데이터 누락(No data), 연도만 표시되어 최신성 판단이 어려운 항목은 ‘담당자 확인 필요’로 분류

실행 방법

1

브라우저 탐색이 가능한 AI 에이전트에서 프로젝트를 엽니다.

2

점검 대상과 방식을 질의어로 입력합니다.

3

AI가 Markdown 규칙을 읽고 페이지를 탐색한 뒤 결과를 저장합니다.

예시 질의어: “대표 홈페이지와 과수생육 사이트 증분 점검해줘.”

운영 시 브라우저 사용량과 동적 페이지의 특성에 따라 점검 범위가 제한될 수 있으며, 최종 조치 여부는 담당자가 확인합니다.
